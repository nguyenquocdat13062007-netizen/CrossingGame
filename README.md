# [Crossing Game]
Environment:** Visual Studio 2022 (`v143`), C++20, SFML 3.x

---

## ?? How to Play

1. Run `[CrossingGame].exe` located in the root / build folder.
2. Ensure the `assets/` folder and `.dll` files remain in the same directory as the `.exe`.

### Controls
* **Movement:** `W`, `A`, `S`, `D` or Arrow Keys
* **Pause / Menu:** `Esc`
* save game progress: `L`
* **Load Game:** `T`
